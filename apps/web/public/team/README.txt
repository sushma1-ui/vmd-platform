Guidance for a matched set (see the site brief):

  - The site frames them in a light, warm frame with a gold hairline, a gentle
    desaturation, and a soft base grounding (see TeamCard.astro / MeetTeam.astro,
    .lc__portrait--photo / .mtc__portrait--photo) so different source photos read
    as one consistent, on-brand set.
