# @vmd/cms — admin + content API (Payload 3)
Payload is the SOLE admin (ratified). Content types are collections here, never
packages (§2.3). Deploys on Vercel with the pooled Supabase Postgres connection
(Supavisor) + Supabase Storage. Module 0 ships the shell + Users; the full content
model arrives in the Database and Admin modules.
